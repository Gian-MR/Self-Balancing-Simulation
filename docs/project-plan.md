# Learning milestones

1. Run fall mode. Explain why the angle increases without motor force.
2. Run balance mode. Observe the cart initially moving beneath the falling tip.
3. Read the model equations and locate each term in physics.py.
4. Change one physical parameter at a time and compare saved plots.
5. Reduce the control interval from 0.01 to 0.005 seconds and compare results.
6. Add small sensor noise and compare accuracy and motor effort.

Possible later extensions: pushes, state estimation, sensor delay, motor dynamics,
finite track, a fixed controller tested against uncertain mass, or a MuJoCo model.
Swing-up is a separate controller project after near-upright balancing works.
